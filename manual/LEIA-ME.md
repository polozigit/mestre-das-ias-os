# Manual de uso da Empresa IA

Esta pasta ensina a pessoa a usar o sistema. Ela não deve ser carregada inteira em toda tarefa. Abra somente o capítulo relacionado à dúvida atual.

## Capítulos

- `como-trabalhar.md`: começar uma tarefa e usar as Skills.
- `conexoes-e-seguranca.md`: usar conectores, APIs e credenciais com segurança.
- `modelos-e-esforco.md`: escolher modelo e nível de esforço.
- `sessoes-e-contexto.md`: continuar, encerrar ou abrir outra conversa.
- `qualidade-e-encerramento.md`: revisar a entrega e preparar continuidade.

Atualize este manual quando a forma de usar o sistema mudar. Não coloque fatos empresariais aqui.
